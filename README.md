🏛️ Анти-ИИ Квен Академия | Полный тренажёр ЕГЭ-2026 по истории

English: Anti-AI Qwen Academy | Full History EGE-2026 Trainer


Бесплатный, автономный HTML-тренажёр для подготовки к ЕГЭ по истории 2026 года. 

Работает без интернета, без регистрации и без рекламы. Поддерживает переключение интерфейса между русским (RU)

и английским (EN) языками.

✨ Особенности проекта

🌐 Двуязычность (RU/EN): Полная локализация всех заданий, пояснений и интерфейса.

Идеально подходит для международных школ и студентов, изучающих русский язык или историю России на английском.

⏱️ Экзаменационный таймер: Встроенный секундомер с пресетами:

Экзамен: 210 минут (3 часа 30 минут — формат ЕГЭ-2026).

Тренировка: 60 минут.

Визуальные предупреждения при истечении времени.

📚 21 Задание (Часть 1 + Часть 2):

Часть 1 (12 заданий): Автоматическая проверка ответов. Охватывает все периоды: от Древней Руси до современной России. Темы: хронология, персоналии, культура, карты, анализ источников.
Часть 2 (9 заданий): Задания с развёрнутым ответом (13–21). Включают контекст источника/изображения, требования ФИПИ к оформлению и скрытые эталоны ответов для самопроверки.

🔒 Полная автономность: Один HTML-файл. Не требует установки Python, Node.js или подключения к серверам. Работает прямо из браузера (file:///).

🛡️ Anti-AI Approach: Задания составлены так, чтобы проверять глубокое понимание исторических процессов, а не просто поиск фактов. Включены подробные объяснения, помогающие отличить факты от выдуманных ИИ данных.

✅ Самопроверка: Варианты ответов перемешиваются случайным образом. Правильный ответ открывается только после выбора варианта. Есть чек-лист подготовки и план занятий на 25 дней.
